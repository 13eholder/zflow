# 对象存储服务概要

该服务需要对外提供公共操作：写入对象、读取对象、删除对象以及按前缀分页列举对象。调用方包括其他内部服务和多租户的客户端，因此契约必须在滚动升级期间保持新旧节点兼容。

已知约束：

- 请求来自不受信任的多租户客户端，每个请求都需经过鉴权。
- 对象键为 1 到 1024 字节的 UTF-8 字符串，按桶（bucket）隔离租户命名空间。
- 对运维人员来说，对象不存在和对象已被删除（存在删除标记）必须是可区分的，但公共 API 不得暴露内部副本与分片细节。
- 列举结果允许最终一致，最多延迟一分钟反映最新写入。

尚未决定：

- 调用方是否可以使用条件写（如仅在对象不存在时写入）。
- 桶是否默认开启版本控制。
- 列举操作是否需要与读对象不同的鉴权级别。
