# 磁盘健康监控与自动隔离规格

当磁盘出现慢盘特征或介质错误时，运维可以选择接收告警并触发自动隔离。监控偏好（灵敏度、是否允许自动隔离）按集群存储，默认仅告警不隔离。SMART 指标采集已经存在；延迟离群检测每十五分钟运行一次。

需求：

- 添加具有边界验证的监控配置读取/更新 RPC。
- 从 SMART 采集和延迟检测流程中发布隔离评估任务。
- 按磁盘、节点、事件类型和事件版本对任务进行去重。
- 通过现有的告警通道适配器发送告警。
- 记录隔离决策与执行状态，但不存储原始 SMART 全量数据。
- 通过功能开关控制自动隔离路径；禁用状态保持为安全默认值（只告警）。

验证必须包括配置 RPC 测试、任务去重测试、适配器集成测试以及一个端到端慢盘隔离场景。自动换盘、跨集群联动或监控历史 UI 不在范围内。
